## 🧠 Overview

**OptiScaler** is a PC graphics utility designed to expand the upscaling and frame-generation options available in compatible games. It can provide a flexible layer between supported rendering technologies, allowing users to experiment with different image reconstruction and frame-generation solutions on suitable hardware.

The project is particularly useful for users who want to explore alternative upscalers or frame-generation technologies when a game does not natively expose the desired option. Depending on the game and configuration, it can work with technologies from different graphics ecosystems.

OptiScaler is aimed at PC gamers and enthusiasts interested in improving rendering performance, increasing perceived frame rates, and fine-tuning modern graphics features across compatible titles.

## Additional Information for Windows Users

OptiScaler is intended for users who want more flexibility when working with modern PC rendering technologies. By providing a configurable compatibility layer, the utility can make it possible to experiment with different upscaling and frame-generation implementations in games where the preferred technology may not be directly available.

Upscaling can lower the internal rendering resolution and reconstruct the final image at a higher output resolution, potentially reducing GPU workload. Frame-generation technologies can then create additional intermediate frames to make motion appear smoother when the underlying rendering performance is sufficient.

Results vary depending on the individual game, graphics API, GPU architecture, driver configuration, and selected options. Advanced users should therefore test settings individually and compare image quality, latency, and performance when configuring each title.
